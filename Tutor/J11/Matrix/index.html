旋轉 R 與鏡射 M 的關係

學測數學總複習｜正負 × 秒殺口訣 × 幾何視覺化

💡 一、秒殺・不死背展開
全場通殺・10字口訣
「 正 R 負 M，加減看左邊 」
  • ① R 為 ＋、M 為 － 同號 R / 異號 M
  • ② 左邊是 R (＋) 角度相加 ( θ + φ )
  • ③ 左邊是 M (－) 左減右 ( θ − φ )
筆記版・四大公式直接背
「 M(φ) 為準，左加右減 」
  • R(θ) · M(φ) = M(φ + θ) 乘左加 θ
  • M(φ) · R(θ) = M(φ − θ) 乘右減 θ
  • M(θ) · M(φ) = R(θ − φ) 雙鏡左減右
  • R(θ) · R(φ) = R(θ + φ) 雙轉直接加
考場忘光救命術
「 只看 ( 1 , 0 ) 落點角度！」
  • 原理：
    R(ψ)、M(ψ) 第一行皆為 [cos ψ, sin ψ]ᵀ，
    即 ( 1 , 0 ) 變換後的落點角度 ψ！
  • 實戰：求 M(φ)·R(θ) ( 由右往左 )
    ( 1 , 0 ) ➔ 先轉 θ ➔ 對 φ/2 鏡射 ➔ 落點 φ − θ
⚠️ 學測必考「 兩倍角 」防呆：
對「 斜角 」α ( 斜率 m = tan α ) 鏡射時，
角度是 φ = 2α！ 算完若問「 新鏡射軸斜角 」記得 ÷ 2
